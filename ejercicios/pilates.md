# Ejercicio Pilates

## Descripción
El Pilates es un sistema de ejercicios que fortalece el cuerpo, mejora la flexibilidad y promueve la conexión mente-cuerpo.

## Beneficios
- Mejora la postura y el equilibrio.
- Fortalece el núcleo y la columna vertebral.
- Aumenta la flexibilidad.

## Instrucciones
1. Comienza con un calentamiento de 5-10 minutos.
2. Realiza los ejercicios de Pilates (como el "Cien", "Rolling Like a Ball", o "Teaser") durante 30-45 minutos.
3. Termina con un enfriamiento y estiramientos.
